# Residence Massacre — Fullbright + TP Speed + Stamina + ESP + автозабор

Клиентский скрипт под **Residence Massacre**: **Fullbright**, **Speed через телепорт** (TP walk), **бесконечная стамина**, **ESP игроков / монстров / мутантов / предметов**, **автозабор предметов** и выбор **вида камеры** (1-е / 3-е лицо).

Меняет только клиентские свойства (`Lighting`, камера, `HumanoidRootPart` CFrame, значения стамины, Highlight/BillboardGui). `WalkSpeed` не трогается. Никакого обхода защиты или античита нет.

> **Про скорость:** прямой `WalkSpeed`-чик сервер валидирует и кикает на движении. Поэтому скорость сделана через **TP walk** — сервер видит телепорты позиции, а не скорость. Это другая механика, но если игра палит и сами телепорты, кикнёт так же — обходить не будем.

---

## Запуск одной строкой

Вставь в executor и нажми Execute:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/ResidenceMassacre/refs/heads/main/ResidenceMassacre.lua",true))()
```

Или используй `loader.lua` — он тянет тот же файл и пишет в консоль причину, если что-то пошло не так.

### Привязки к игре больше нет (с v4.29)

Старая проверка на Residence Massacre (`RM_GAME_ID` / `ONLY_PLACE_IDS`) **убрана по запросу** — меню и скрипт открываются в **любой** игре. Важно понимать поведение вне RM: игровые фичи (генератор, провода, ящик, автозабор и т.п.) сами ничего не найдут и молчат — автофичи выключены по умолчанию; общие фичи (Fullbright, ESP, TP walk, стамина, Noclip, темы, бинды) работают везде. ТП-кнопки и паника по-прежнему защищены своими плейс-гейтами — в чужой игре/чужой карте они откажут уведомлением, а не полетят в пустоту.

## Возможности

| Элемент | Что делает |
|---|---|
| **Fullbright** | `Brightness`, `ClockTime = 14`, белые `Ambient` / `OutdoorAmbient` / `ColorShift` + **туман и тени всегда убраны**, пока включён: `FogStart/FogEnd` **и туман `Atmosphere`** (`Density/Haze` — он перебивает Fog*, поэтому виден до сих пор) + поздний повтор на кадре, если игра возвращает туман своим скриптом (кнопка «No fog» убрана — это часть Fullbright). Свет перепроверяется **на каждом кадре** — без мерцания |
| **Brightness** | слайдер 0–10, шаг 0.5 |
| **Speed (TP walk)** | тогл скорости — движение телепортом корпуса по WASD, Shift = x1.6; **не проходит сквозь стены и предметы** (рейкаст перед собой на уровне корпуса и колена, низкие ступеньки перешагивает) |
| **TP speed** | слайдер 10–300 studs/s (по умолчанию 50, выключено) |
| **Бинды** | **все по умолчанию `None` (пусто)** — полклавиши не занято; назначаются кликом по боксу бинда: Speed (TP walk), Infinite stamina, Auto pickup, Auto fuel (Ночь 1), Auto PowerCell (Ночь 2), Anti-Freeze, Infinite O2, Noclip, аимбот (зажать, Ночь 3), паника-ТП (ТП). Технические детали (v4.27): пустой бинд под капотом хранится как валидный геймпад-код `ButtonX` — `"None"` кидал бы ошибку на каждом вводе (`Enum.KeyCode["None"]` невалиден), а сентинел `Unknown` в v4.26 оказался ловушкой: Roblox отдаёт `KeyCode.Unknown` на клики мыши/колесо/тап → каждый клик запускал все бинды; `ButtonX` не совпадает ни с клавиатурой, ни с мышью, ни с тапом. Витрина показывает «None» (свип только по боксам `KeybindBox`: при старте и тремя проходами +4.6/5.6/7.6 с — мусор `None`/`Unknown`/`MouseButton*`/`ScrollWheel` из старого конфига вычищается сам; **валидную сохранённую клавишу санити не трогает** — её уберёт только кнопка **«Сбросить все бинды (None)»** в Settings) |
| **Infinite stamina** | тогл — короткое наблюдение (~1.2с) при включении находит стамину (какая падает при беге), дальше крутится только она; рескан лишь при респавне. Пока включена — внизу экрана зелёная плашка «БЕСКОНЕЧНАЯ СТАМИНА: ВКЛ» |
| **Infinite O2** | тогл + бинд (по умолчанию `None`): `Breath` держится на максимуме (`Max`-атрибут + значение, запись только при отличии), заодно гасит `Blur` и `HeavyBreath` — не задыхаешься |
| **Infinite Battery** | тогл: заряд фонаря `Flashlight.Battery` держится на 130 (и в руках, и в рюкзаке) — фонарь не садится |
| **Тревога кабины** | тогл **«Кто-то лезет в кабину»** (Воспоминания): слушает `Remotes.OpenDoor` — когда **другой игрок** открывает кабину, приходит уведомление «Вторжение в кабину: &lt;имя&gt; открывает «&lt;дверь&gt;»» (свой вход не тревожит) |
| **Тревога двери** | тогл **«Мутант у входной двери (Growling)»** (Воспоминания, v4.30): опрос раз в 0.5 с — пока на `FrontDoor.SoundPart.Growling` играет звук, уведомление «⚠ Мутант у ВХОДНОЙ двери!» с кулдауном 15 с (из gueston) |

| **Kid Detector** | тогл **«Детект ребёнка (GhostChild)»** (Воспоминания): раз в секунду скан на детей (`GhostChild`/`kid`); появление рядом (&lt;60 м) — уведомление, всё — в консоль (из snippet ScriptBlox 55878) |
| **Disable Static** | тогл (Игрок → «Прочее»): глушит оверлеи помех (`static`/`noise`/`vhs`/`glitch` в PlayerGui/CoreGui, свои GUI не трогает); выключение возвращает помехи. Пометка переживает перезапуск скрипта: новый запуск **всегда стартует с тоглом OFF** и сам возвращает помеченные помехи (~1 с). Если оверлеи с такими именами не найдены — скрипт попросит реальное имя из Explorer |
| **Паника-ТП** | бинд (по умолчанию `None`) + кнопка в ТП: случайное укрытие **текущей** карты (Н1 — крыша/спальня; Н2 — список выбирается по высоте персонажа: старая карта y≈6–26 / новая y≈82; бункер — сейф-плейс; Н3/лобби — укрытие по имени Cabin/Lodge/Closet). Координаты чужой карты не используются — не улетишь в пустоту |
| **Anti-Freeze** | тогл + бинд (по умолчанию `None`): в игре `Character.Temperature` — это **LocalScript**, тогл его выключает (при выключении тогла включает обратно); плюс держит `Freeze = 0`, запись только при отличии (без десинка) |
| **Noclip** | тогл + бинд (по умолчанию `None`): коллизии персонажа выключены — идёшь сквозь стены; выключение возвращает стены сразу. Включать осознанно |
| **Под землю при опасности** | тогл + слайдер «Радиус опасности» (30–300, по умолчанию 100 ст), вкладка **Игрок** — **замена God Mode** (тот не спасал: сервер сам перезаписывает HP): монстр ближе радиуса → персонаж уходит под землю на 40 ст (Y пинится каждый кадр, коллизии выключены), а камера остаётся сверху над точкой персонажа и ходьба — точно как обычно (WASD считается от текущей камеры); сервер видит персонажа глубоко под поверхностью — монстр не достаёт. Всплытие: монстр дальше радиуса+30 (гистерезис) или тогл OFF; дистанция меряется от точки **на поверхности** (монстр над тобой = всё ещё опасно); респавн и re-run — авто-восстановление (камера + подъём на поверхность) |
| **Anti-Kick** | **всегда при старте** (без тогла): у локальной копии `Remotes.Kick` отключаются все обработчики `OnClientEvent` (`getconnections` → `Disconnect`) — клиентская кик-логика молчит; **сам ремоут НЕ удаляется** (v4.34: раньше было `Destroy()` — на Ночи 3 это кикало с Error 267 сразу после запуска, её анти-чит требует `Remotes.Kick` в дереве), повтор на каждом спавне. Серверный Kick с клиента не блокируется — честное ограничение |
| **Player ESP** | тогл + палитра — хайлайт и метка «имя [дист] HP» по всем игрокам сквозь стены |
| **Monster ESP** | тогл + палитра — любая модель с `Humanoid`, не являющаяся игроком (имена монстров находит сам), **плюс** модель `Monster` из Воспоминаний без Humanoid (`AnimationController`, корень `RootPart`; v4.32 — один клик подсвечивает и её, спавн ловится сразу, метка «имя [дистанция]» без HP). Заодно этот монстр учитывается в камерном аиме и «Под землю при опасности» |
| **Mutant ESP** | тогл + палитра — красный хайлайт и метка «MUTANT [дист] HP» **со состоянием** из `Config` (— ДОГОНЯЕТ! / — ИЩЕТ / — активен; при погоне метка краснеет) + сообщение в консоль при переходе в `Chasing`; сюда же попадает **BunkerRat/Abomination** из бункера; постоянный скан раз в 1с + события спавна, очистка при переименовании |
| **Item ESP** | тогл + палитра — **любой** `ClickDetector` / `ProximityPrompt` в workspace: еда из `ItemSpots` (BloxyCola, Food), JerryCan, Generator и т.п. Спавн предмета подхватывается сразу, без ожидания скана. Плюс **WorkerHead** (голова рабочего, Ночь 3, v4.30 из gueston) — предмет без `ClickDetector`, метку ставит по имени; в автозабор не идёт (там гейт `e.prompt or e.cd`) |
| **Скорость действий** | слайдер 0.03–5 с (по умолчанию 0.1) — кулдауны автозабора и паузы авто-заправки; меньше = всё делается быстрее (если сервер не принимает действия — подними). **Важно:** между циклами авто-заправки есть ещё жёсткий общий лимит ≥3 с — слайдер его не снимает |
| **Auto pickup** | тогл + бинд (по умолчанию `None`) + выпадашка **«Что забирать»** (несколько пунктов, «Все» = всё подряд): телепорт к предмету → взаимодействие → возврат; кулдаун по каждой цели — из «Скорость действий», генератор пропускает — им занимается Auto fuel |
| **Auto fuel** | тогл + бинд (по умолчанию `None`), вкладка **Ночь 1** → «Генератор»: телепорт к **JerryCan** → взять (стоим рядом) → телепорт к **Generator** → подать топливо → обратно. Паузы — из «Скорость действий» (плюс жёсткий общий лимит ≥3 с между циклами — слайдер его не опускает). Для сервера — «стоял рядом и жал кнопки» |
| **Auto PowerCell** | тогл + бинд (по умолчанию `None`), вкладка **Ночь 2**: свободная капсула `PowerCell` (вне `Generator`, с `ClickDetector`) → телепорт рядом (**обязательно стоя рядом**) → клик → доставка к `Generator` → клик по слоту **`Generator.Detector.ClickDetector`** → вставка (модель генератора выбирается по наличию `Detector` и близости — чужой/деко-генератор не берётся, выбранный слот печатается в консоль). 4 неудачные попытки → авто стоп + сообщение в консоль |
| **Дюп предметов** | слайдер «Повторов дюпа» (1–10) + кнопка-серия, **все вкладки ночей (Ночь 1 / Ночь 2 / Ночь 3)**: каждое воскрешение (ремоут `LoadCharacter`) дублирует предметы — новый набор выдаётся снова, старый остаётся; серия ×N с паузой 2.5 с (> кулдауна FireServer 2 с — иначе Error 267), повторный клик не пускает вторую серию, ход пишется в консоль. Одиночный дюп — кнопка «Revive (воскрешение)» (Ночь 2) |
| **Порог топлива** | слайдер 0–100% (по умолчанию 50): авто-заправка срабатывает **только когда топлива меньше порога** — не постоянно, а когда нужно (0 = никогда, 100 = всегда). Уровень читается из Value/атрибута/текста генератора; если прочитать не удалось — заправляет всегда (пишет в консоль) |
| **Заправить сейчас** | кнопка рядом с порогом: один полный цикл (канистра → генератор) вручную, когда захочешь — независимо от Auto fuel и порога |
| **Запустить цели (радио)** | кнопка (**Ночь 1 → Старт ночи**, v4.30 из prolover): ТП к радио → клики по его `ClickDetector` каждые 0.5 с до `GameState.Active` (таймаут 12 с) → возврат на место; `pickupBusy`-гвард + кулдаун кнопки |
| **Отключить метель (Blizzard)** | тогл (**Ночь 1 → Погода**, v4.30 из prolover): `GameState.Blizzard.Value = false` **локально** (сервер правки клиента не видит — если метель считает сервер, не поможет); исходное значение кэшируется и возвращается при выключении и при re-run |
| **Бесплатные апгрейды (эксп.)** | кнопка (**Ночь 1 → Генератор**, v4.30 из diddy): `RS.Upgrades.Generator` → `Max=∞`, `Price=0` локально + магазин `UpgradeShop`/`Gambler` из `RS.Assets` показывается в workspace; если сервер цену валидирует сам — не сработает, notify честно сообщает результат |
| **Анти-лаг (Potato)** | тогл (**Settings → Производительность**, v4.30 из prolover): все `BasePart` → `Plastic` + `Reflectance 0`, декали/текстуры скрыты, вода без бликов/волн; исходные значения в атрибутах `RM_Pot*` — выключение и стартовый блок при re-run возвращают детали как были |
| **Auto electric** | вкладка **Ночь 1** → «Электрика»: битый провод (`Highlight`-контур **или включённые искры `Sparkles`** — сверено по RMxploitt) → **нет ключа (`Wrench`) → телепорт к `WrenchGiver` и берём** → открываем ящик (`FuseBox` Detector) → телепорт к проводу → клик **ремоутом `ClickWire`** (проверенный путь; `ClickDetector` — запасной, если ремоута нет) → чинится. Если провод не берётся дважды — щёлкаем ящик заново (вдруг закрыт). Работает **только при вырубленном питании** (`GameState.FusesFried = true` — иначе сканировать нечего); при новой аварии счётчики/флаг ящика сбрасываются. Автозабор провода/ящик/ключ не трогает. При смене количества битых в консоль печатается отладка `HL=/SP=/ST=` — если детектор врёт, пришли строки |

Подписи-описания под элементами убраны — только названия и секции. Конфиг хранится в папке `RMScripts`.

**ESC-защита:** окно Rayfield ищется глубоко (CoreGui / `gethui()` / RobloxGui), лежит в `CoreGui` с `DisplayOrder 100000`, а watchdog каждые 0.2с возвращает выключенное, пересоздаёт удалённое (окно, плашка стамины, контейнер ESP) — при открытии меню паузы интерфейс больше не пропадает.

**Без мерцания:** свет и камера перепроверяются **на каждом кадре**, но запись свойства происходит **только если оно реально отличается** — раньше опрос раз в секунду позволял игре возвращать темноту между опросами (видно как мерцание), а частые записи вызывали desync и кик с Error 267.

**Автозабор:** пока цель дальше радиуса активации — телепорт `HumanoidRootPart` над предметом, пауза 0.1с (позиция доходит до сервера), взаимодействие, возврат. На ходу автозабора TP walk заморожен, чтобы не перебивать телепорты.

**Speed (TP walk) по умолчанию ВЫКЛ** и не сохраняется в конфиг. Fullbright работает сразу после запуска.

**TP walk без рывков вверх:** высота стойки замеряется рейкастом (не хардкод), рейкаст на землю **каждый тик** (иначе на лестницах ступени перепрыгивались), подъём максимум 2.5 студы за шаг, спуск — не быстрее 5 студ за тик.

**Сквозь предметы не проходим, но по ступеням лезем:** на уровне головы любое препятствие = стена (шаг обрезается перед ней); корпус/колено меряют высоту рейкастом сверху — до 2.5 студ (ступенька, пандус, ящик) можно заходить, выше — останавливаемся; земля под концом шага тоже проверяется.

**Плавный телепорт везде:** все телепорты авто-действий (автозабор, авто-заправка, электрика) летят через `TweenService` (Sine InOut). Скорость — слайдер **«Скорость твинов»** (Игрок → Скорость), 50–1000 студ/с, по умолчанию 500; длительность 0.05–3 с по расстоянию. Слайдеры «Скорость твинов» и «Скорость действий» без флагов — в конфиг не пишутся, их значение живёт в `getgenv` до конца сессии (после re-run стартует с последнего значения; сброс — перезапуском Roblox). TP walk не тут: он двигает каждый кадр маленькими шажками и и так плавный.

## Флаги (задать до запуска)

```lua
getgenv().RM_FB         = true  -- fullbright (+ всегда без тумана)
getgenv().RM_Bright     = 3     -- яркость 0..10
getgenv().RM_TPSpeedVal = 50    -- скорость TP walk 10..300 studs/s
getgenv().RM_CamMode    = "game" -- камера: "game" / "first" / "third"
getgenv().RM_ActionDelay = 0.1   -- кулдауны автозабора/авто-заправки, с (0.03..5)
getgenv().RM_FuelThreshold = 50  -- авто-заправка ниже уровня, % (100 = всегда)
getgenv().RM_TweenSpeed = 500    -- скорость плавных телепортов, студ/с (50..1000)
```

> **Приоритет конфига:** у `RM_FB`, `RM_Bright`, `RM_TPSpeedVal`, `RM_FuelThreshold` и камеры есть флаги Rayfield — сохранённый GUI-конфиг (`RMScripts/ResidenceMassacre.json` в рабочей директории файлов экзекутора; путь собирает Rayfield из `FolderName`/`FileName`) подгружается через ~4 с и **перебивает** этот пресет. Чтобы пресет сработал — удали файл конфига перед запуском. У `RM_ActionDelay` / `RM_TweenSpeed` флагов нет — их пресет работает всегда.
>
> **Тоглы без `Flag`** (Speed, Стамина, Noclip, Auto pickup, Auto fuel, Auto electric, Disable Static, Тревога двери, Отключить метель, Анти-лаг и ещё ~8 — всего 18 тоглов) в конфиг **не пишутся**: после рестарта Roblox они стартуют с OFF, в отличие от биндов/ESP/цветов, которые восстанавливаются. Состояние живёт в `getgenv` до конца сессии (переживает re-run внутри сессии).

## Про античит

Скрипт трогает только клиентские свойства. Если игра серверно возвращает их обратно — обходить её реакцию скрипт не будет.

## Ответственность

Использование — на свой страх и риск, правила игры лучше прочитать.
