## 2. ✅ Что делаю (полный список)

### Движение (только твой клиент)
- TP walk — плавное перемещение корпуса по WASD (TweenService, **не** сквозь стены)
- Скорость твинов слайдером; никакого прямого WalkSpeed (кик-ловушка)
- Noclip (по осознанному включению)
- «Под землю при опасности» — автоспасение от монстра
- Паника-ТП в укрытие по бинду; кнопки ТП по точкам карты (с гейтом по плейсу)
- Расхлёбывание «залипших» состояний: анкор, фриз, регдолл, камера

### Выживание и фармы
- Infinite стамина / кислород / батарея фонаря
- Fullbright без мерцания; анти-лаг (Potato); глушение помех (Disable Static)
- Автозабор предметов, авто-заправка генератора, авто-электрика, авто-запуск ночи
- Любые авто-кликеры и обходы точек: TP рядом → клик по `ClickDetector`/
  `ProximityPrompt` → дальше по кругу (фарм конфет/дров/капсулы и т.п.)
- Дюп предметов через `LoadCharacter` (пауза ≥2.5 с между ревайвами)
- Игровые ремоуты, которые делают то же, что может игрок руками
  (`Repair`, `Delivery`, `Unhide`…) — по явному «если надо, бери ремоут»
- Локальные апгрейды/показ магазинов, если сервер их принимает

### Инфо (не вредит никому)
- ESP: игроки, монстры, мутанты, предметы — метки и хайлайты сквозь стены
- Детекторы/тревоги: кто открыл дверь, мутант у двери, ребёнок рядом, атака монстра
- Камерный аим на монстров (PvE: только камера, урона нет)
- Диагностика в консоль: что не найдено, почему не сработало, сырые значения

### Интерфейс и код
- Вкладки, тоглы, слайдеры, кнопки, бинды (по умолчанию `None`), тема,
  палитры, конфиг с автозагрузкой
- Баг-фиксы по тестам, бекапы перед каждым пушем, README/NOTES
- Портирование фич из чужих скриптов — **только читаемый код**
- Скрипты под другие игры (PvE): фармы, выживание, ТП, ESP — тот же подход

## 3. ❌ Чего не делаю (полный список)

### Против живых игроков
- Флинг, толчки, ловушки, урон, кик, убийство других игроков
- Любой гриф чужой игры в лобби
- Крашеры лобби/серверов

### Обходы защиты
- Обход античитов, Adonis, киков (в т.ч. `Remotes.Kick`)
- `hookmetamethod` / хук `namecall` / чтение закрытых скриптов ради обхода
- `Destroy()`/`Delete()` любых игровых объектов (ремоутов, дверей, хитбоксов, защит)
- Обфусцированные и закодированные скрипты — читать нечего, не беру
- Прямой `WalkSpeed`/`JumpPower`

### Криминал
- Стилеры куки/паролей/токенов, кейлоггеры
- Взломы, ддос, фишинг, воровство аккаунтов
- Любой код, вредящий людям вне игры
